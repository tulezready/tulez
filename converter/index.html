What it converts

Images
PNG, JPG, WebP, GIF, BMP, ICO, SVG, AVIF, HEIC → PNG, JPG, WebP, BMP, ICO, PDF
PDF
PDF → PNG or JPG (one image per page), TXT
Documents
Word DOCX → HTML, Markdown, TXT, PDF · Markdown ↔ HTML · TXT → PDF, HTML
Spreadsheets
XLSX, XLS, ODS, CSV, TSV, Numbers → XLSX, ODS, CSV, TSV, JSON, HTML
Data
JSON ↔ YAML · JSON or YAML records → CSV, XLSX
Audio & video
MP3, M4A, OGG, FLAC, MP4, WebM… → WAV · video → still frame PNG or JPG
Archives
Anything → ZIP · ZIP → its files
